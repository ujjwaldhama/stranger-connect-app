# Stranger Connect — Premium Edition

This is the first Flutter UI starter for the separate Stranger Connect app.

## Included now
- Premium black-and-gold theme
- Discover, Friends, Premium and Profile navigation
- Find Stranger and Chat with Friends entry points
- Basic empty states and UI placeholders

## Not connected yet
Authentication, database, matching queue, real-time chat, friend invite links, notifications, payments, moderation and admin dashboard.

## Run
1. Install Flutter SDK and Android Studio on a computer.
2. Extract this folder.
3. Run `flutter pub get`
4. Run `flutter run`

To build an APK: `flutter build apk --release`

The backend architecture is outlined in `backend/README.md`.
